# AI-Learning-Journal
This is a journal to document my AI learning journey and house the projects I am building.

### Project 1: Calorie Calculator App - Lovable

## Learning Notes
### **1. The Fundamentals of Vibe Coding**
*   **Framework:** **Thinking, Frameworks, Checkpoints, Debugging, and Context**.
*   **The 4 Levels of Thinking:** Define a project through **Logical** (the what), **Analytical** (the tools), **Computational** (the logic), and **Procedural** (the user excellence) thinking.
*   **Defining Context:** Create a **Product Requirements Documents (PRD)** and providing visual "inspo" mockups to guide the AI’s output.

### **2. Technical Frameworks and Safety**
*   **Version Control (Git/GitHub):** Use **Git** to create "checkpoints" is essential. Initialize a repository, commit changes, and push them to **GitHub** to ensure having a safe "save point" to roll back to.

### **3. App Building & Troubleshooting**
*   **Workflow Modes:** Identify whether it is in **Implementation Mode** (adding features) or **Debugging Mode** (fixing errors) and how to provide the right context for each.
*   **Methodical Debugging:** Instead of just saying "it doesn't work," provide **full error messages** and **screenshots** to the AI for more effective fixes.
